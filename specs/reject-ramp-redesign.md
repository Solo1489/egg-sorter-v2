## 3. เงื่อนไขที่ต้องผ่านตอนลงมือ (ให้ `check.py` ตรวจ)

1. F1 กวาดผ่านทุกมุมตั้งแต่ STOP ถึง REJECT แล้วไม่ชนผนัง ฝา K1 ลูกกลิ้ง หรือสะพานตายตัว
2. ไข่ออกแบบ 48 × 65 ไม่จมเข้าไปในชิ้นส่วนตลอดทางลาด → แอ่ง → ถาดหน้า และตลอดทาง ลูกกลิ้ง → F1 BRIDGE → สะพาน → แท่นชั่ง
3. ไข่ในแอ่ง รวมตอนขึ้นเนินแล้ว ผิวบนไข่ต่ำกว่าผิวล่างของสะพานตายตัวอย่างน้อย 3 มม. และไม่เข้าไปใต้ load cell
4. ปลายบาน F1 ตอน BRIDGE เว้นห่างสะพานตายตัว ≤ 2 มม. (ไข่ข้ามได้ไม่สะดุด) และสะพานไม่แตะแท่นชั่ง เว้น ≥ 1.5 มม. (ไม่รบกวนการชั่ง)
5. ไข่เสียเลนหลังไหลออกด้านหน้าได้โดยลอดใต้ F1/สะพานของเลนหน้า (เลนหน้าอยู่ STOP หรือ BRIDGE)
6. ชุดรางทั้ง 3 ชุดดึงออกด้านหน้าได้ครบระยะ
7. ตัวเซอร์โว MG996R (~41 × 20 × 43 มม.) ไม่ชนชิ้นอื่น
8. ความยาวเครื่องรวม ≤ 1000 มม. และ `npm run verify` ผ่าน

## 4. สิ่งที่ยังต้องเช็กกับของจริง

- ความเร็วไข่ที่ท้ายทางลาด ประมาณ 0.9–1 m/s ต้องลองว่าแอ่ง + โฟม หยุดไข่ได้นุ่มพอ ถ้าไม่พอ ให้เพิ่มม่านซิลิโคนที่ปลายทางลาด
- กระแสของ MG996R ตอนกระชาก (~2.5 A) ใช้ buck 5V 5A ร่วมกับเซอร์โวตัวอื่น ต้องเช็กว่าไฟไม่ตก
- วัสดุม่านกันแสง และว่ามืดพอสำหรับโหมดส่องล่างหรือไม่
