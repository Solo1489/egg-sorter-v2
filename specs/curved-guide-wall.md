## 1. ปัญหาของครีบเฉียงเดิม (สเปก 2026-11-16)

ครีบ `out.*.fin.*` เป็นแผ่นตรงยาว 18 หนา 4 เอียง 45° สูง 34 มม. จากพื้น อยู่ที่ปลายหลังของไข่ ไข่กลิ้งมาตาม +X โดยแกนยาวขนาน Y ปลายหลังชนครีบ ปลายหน้าวิ่งต่อ ไข่จึงหมุน 90° แล้วกลิ้งไปถาดหน้า

| เรื่อง | ค่าในแบบเดิม |
| --- | --- |
| ความเร็วไข่ตอนแตะครีบ (จาก `animation.json` ยังไม่คิดแรงต้านการกลิ้ง) | 0.76–1.10 m/s |
| มุมผิวครีบเทียบกับทางวิ่ง | 45° → ความเร็วตั้งฉากผิวตอนชน 0.54–0.78 m/s (เกินเกณฑ์ตอนไข่ลงพื้นที่ 0.3 m/s ไปมาก) |
| จุดที่ไข่ชน | ปลายครีบเป็นสันเหลี่ยม ไข่ที่เบี่ยงในเลน (เลนกว้าง 74 ไข่ยาว 65 เบี่ยงได้ข้างละ 4.5) ชนสันได้ |
| ช่องระหว่างครีบเลนหน้ากับไข่เลนหลังที่กลิ้งผ่าน | 1 มม. (`turned_x(gap=1.0)`) เบียดมาก |
| ครีบเลนหลังกับโฟมกันชนท้ายแอ่ง | แยกกันและมีช่องระหว่างกัน ไข่เข้าไปติดได้ |

## 2. สิ่งที่เสนอ (รอยืนยัน)

นิยาม: **θ** = มุมระหว่างผิวผนัง (มองจากด้านบน) กับแนว +X ที่ไข่วิ่งมา ถ้า θ = 0° ผิวผนังขนานกับทางวิ่ง ไข่ไม่ชน ถ้า θ = 90° ไข่ชนตั้งฉาก ครีบเดิมมี θ = 45°

| # | หัวข้อ | ข้อเสนอ |
| --- | --- | --- |
| C1 | หลักการ | เปลี่ยนครีบทุกรางเป็น**ผนังโค้งนำ** เริ่มที่ขอบหลังเลน (Y = กึ่งกลางเลน + 37) ด้วย θ = 0° แล้วค่อยๆ ชันขึ้น ปลายหลังของไข่จะแตะผนังแบบเฉียดก่อน แล้วไถลไปตามผนังโค้งพร้อมกับหมุน ไม่มีจังหวะที่ไข่ชนสันตรงๆ |
| C2 | เลนหน้า: ครีบโค้ง | โค้งจาก θ 0° ถึง θ_end ≈ 55–60° แล้วจบด้วยปลายมน R ≥ 3 **ไม่ต่อกับกันชนท้ายแอ่ง** เพราะไข่เลนหลังต้องกลิ้งผ่านไปด้านหน้า |
| C3 | เลนหลัง: ข้อศอก | โค้งจาก θ 0° ถึง 90° แล้วต่อสัมผัสเข้ากับผิวโฟมกันชนท้ายแอ่ง (`out.*.stop.foam`) เป็นผนังต่อเนื่อง ไม่มีช่อง |
| C4 | มุมตอนแตะ | ไข่ออกแบบที่อยู่กลางเลนแตะผนังที่ θ_c ≈ 25–30° ความเร็วตั้งฉากผิวลดเหลือ 0.32–0.55 m/s จากเดิม 0.54–0.78 ต้องใช้รัศมีโค้ง R ≈ 35–50 มม. (R(1 − cos θ_c) = 4.5 มม. คือระยะจากขอบหลังเลนถึงปลายไข่) |
| C5 | รับไข่หลายขนาด | ไข่เล็กหรือไข่ที่เบี่ยงไปด้านหน้าเลนจะแตะผนังต่ำลงไปตามโค้ง ที่มุมชันกว่า (ไข่ยาว ~52 มม. ที่เบี่ยง 4.5 มม. แตะที่ θ ≈ 50°) ไข่ที่เบี่ยงไปด้านหลังแตะผนังแบบเฉียดกว่าเดิม ดังนั้นปลายโค้ง θ_end ของเลนหน้าต้องเลยจุดที่ไข่เล็กสุดแตะไปอย่างน้อย 5° |
| C6 | วัสดุ | แกนพิมพ์ 3D (PETG) ผิวด้านที่ไข่แตะหุ้ม EVA 3 มม. สูงจากพื้นอย่างน้อย 34 มม. (เท่าครีบเดิม ปลายไข่อยู่สูงราว 24) ฝังพื้นอะคริลิก 2 มม. ขอบบนมน |
| C7 | ช่องให้ไข่เลนหลังผ่าน | ไข่เลนหลังที่หมุนแล้วกลิ้งไปด้านหน้า ต้องห่างครีบโค้งเลนหน้าอย่างน้อย **3 มม.** เมื่อมองจากด้านบน (เดิม 1) |
| C8 | ความยาวเครื่อง | ยังจำกัดที่ ≤ 1000 มม. ตอนนี้ยาว 985.2 จึงเหลือที่ 14.8 มม. แอ่งยาวขึ้นได้รางละไม่เกิน ~4.9 มม. ประเมินว่าครีบโค้งเลนหน้ายื่นไปทาง +X จากจุดแตะมากกว่าครีบเดิมราว 3–5 มม. และ C7 ใช้อีก 2 มม. **ชนเพดานพอดี** (ดูคำถาม Q2) |

## 3. วิธีทำในโมเดล

- ผนังโค้งแบ่งเป็นท่อนตรง 6–8 ท่อนต่อเลน ทุกท่อนเป็น `prism` ระนาบ `xy` ที่ดันขึ้นตาม Z และ**ต้องเป็นรูปนูนทุกท่อน** (`check.py` ตรวจการชนแบบรูปนูน เหมือนทางลาด B ที่แยกเป็นท่อน)
- id: `out.{key}.guide.{L}.{i}` แทน `out.{key}.fin.{L}`
- `meta.egg_runouts.*`: เปลี่ยน `fins` เป็น `guides` = `{L: [[x, y], ...]}` เส้นผิวด้านที่ไข่แตะ ส่วน `turned` และ `stop_x` ใช้ความหมายเดิม
- ตำแหน่งตาม X: ใช้หลักเดียวกับ `FIN.past_last` คือไข่ต้องลงมาเกือบถึงพื้นก่อนแตะ ส่วนต้นโค้งที่ θ ใกล้ 0 ให้วางบนแผ่นรับได้ ส่วนท่อนที่ไข่แตะจริงต้องอยู่หลัง X = G
- ข้อศอกเลนหลังต้องต่อสัมผัสกับผิวโฟมกันชนที่ `X_STOP` ถ้าหารัศมีที่ทำให้ได้ทั้งมุม θ_c ตาม C4 และต่อสัมผัสพอดีไม่ได้ ให้ยึด θ_c ไว้ก่อน แล้วหยุดถามผู้ใช้
- web3d ไม่ต้องแก้ เพราะสร้าง prism ทุกชิ้นจากข้อมูลอยู่แล้ว (ไม่มีโค้ดอ้างถึง `fins`) แต่ต้องดูว่าชิ้น `xy` ขึ้นรูปถูกต้อง

## 4. เงื่อนไขที่ต้องผ่าน (ให้ `check.py` ตรวจ)

1. ไข่ออกแบบที่อยู่กลางเลนแตะผนังที่ θ_c 22–30° ทุกเลนทุกราง
2. ความเร็วไข่ตอนแตะ × sin θ_c ≤ 0.5 m/s (ความเร็วจาก `anim.py`) ค่าเกณฑ์นี้รอยืนยันใน Q1
3. ไข่เล็กสุด (ความยาวตาม Q3) ที่เบี่ยงในเลน ±4.5 มม. ยังแตะผนังก่อนถึงปลายโค้ง θ_end − 5° ไม่ลอดผ่านปลายครีบโค้ง
4. ไข่เลนหลังขณะกลิ้งไปด้านหน้า ห่างครีบโค้งเลนหน้า ≥ 3 มม. (C7)
5. ข้อศอกเลนหลังต่อกับผิวโฟมกันชนโดยมีช่อง ≤ 0.5 มม.
6. ยอดผนังโค้งไม่ชนสะพานตายตัว (รางเสีย) และสะพาน K2→B (ราง A) และชุดรางทั้ง 3 ชุดยังดึงออกด้านหน้าได้ครบระยะ
7. การตรวจเดิมทั้งหมดยังผ่าน (ชิ้นไม่ทับกัน, ไข่ตลอดเส้นทางไม่จมในชิ้นส่วน, pocket clearance, แรงกระแทกตอนลงพื้น ≤ 0.3 m/s)
8. ความยาวเครื่อง ≤ 1000 มม. และ `npm run verify` ผ่าน

## 5. ทดลองกับของจริงก่อนล็อกแบบ

- ทำแอ่งจำลองเลนเดียว (พื้นอะคริลิกเอียง 5° ตามแบบ) แล้วทำผนังโค้ง 3 แบบ θ_c = 20° / 25° / 30° (ตัดโฟมหรือพิมพ์ 3D แล้วหุ้ม EVA) และทำครีบ 45° เดิมไว้เทียบ
- ปล่อยไข่จากทางลงที่ความสูงตามแบบ แบบละ 20–30 ครั้ง ใช้ไข่หลายขนาดตั้งแต่เบอร์ 0 ถึงเบอร์ 5 และใส่ไข่ทั้งแบบหัวป้านไปด้านหน้าและไปด้านหลัง
- นับผลแยกเป็น: หมุนครบ 90° · ไถลไปด้านหน้าทั้งฟองโดยไม่หมุน · ค้างในแอ่ง · มีรอยร้าว
- **ความเสี่ยงที่ต้องเฝ้าดู:** ถ้า θ_c ตื้นเกิน ผนังจะดันไข่ไปทาง −Y มากกว่าบิดให้หมุน ไข่อาจไถลไปถาดหน้าทั้งที่แกนยาวยังขนาน Y (ดู Q4)
