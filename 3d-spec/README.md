## 1. ระบบพิกัด

- หน่วยเป็น **มม.** แกน **Z ชี้ขึ้น**
- X: ทิศที่ไข่ไหล ซ้าย→ขวา โดย 0 คือขอบซ้ายของถาดป้อน
- Y: หน้า→หลัง โดย 0 คือผิวหน้าของราง ค่าติดลบคือถาดรับที่ยื่นออกด้านหน้า
- Z: 0 คือผิวโต๊ะ
- เลนกว้าง 74 มม.: เลนหน้าอยู่ที่ Y 5–79 (กึ่งกลาง 42) เลนหลังอยู่ที่ Y 84–158 (กึ่งกลาง 121)
- กรอบรวมของเครื่อง: X 0–985.2, Y −130–205.9, Z 0–321.8 (ค่าจริงอยู่ที่ `parts.json → meta.bounding_box`)
- เรียงตามแกน X: ถาดป้อน (0–180) → ตู้ AI (180–318) → กล่องชั่ง (318–985 ยาวถึงท้ายเครื่อง) ข้างในเรียง รางเสีย (337–510) → แท่นชั่ง/load cell (513–595) → K2 + ราง A (595–797) → ราง B (799–982)
- ไข่ออกแบบ 48 × 65 มม. (ไข่ไก่เบอร์ 0 ถึงราว 80 g ทุกรูปทรง + เผื่อ) ช่องลอดและจุดพักของไข่ทั้งหมดคิดจากขนาดนี้ (`meta.egg`)
- ผิวโฟมรางสูง Z 22.0 ที่ Y 0 เอียง 5° ขึ้นไปทางหลัง และ 4° ที่ถาดหน้า ราง A/B ใช้ `meta.chute_surface` รางเสียใช้ `meta.chute_surface_reject` (ตอนนี้ค่าเท่ากัน)
- **แอ่งปลายราง (ทุกราง):** พื้นอะคริลิก (ไข่ออกตัวกลิ้งได้บนพื้นเอียง 5°) + **ครีบเฉียง 45° หุ้มโฟม** ที่ปลายหลังของไข่ (`out.*.fin.*`) + กันชนโฟมท้ายแอ่ง ไข่ลงมาแกนยาวขนาน Y ปลายหลังชนครีบก่อน ปลายหน้าวิ่งต่อ ไข่จึงหมุนจนแกนยาวขนาน X แล้วกลิ้งตรงไปถาดหน้า ครีบเลนหลังอยู่ขวากว่าเลนหน้า ≥ 12 มม. ให้ไข่เลนหลังกลิ้งผ่านครีบเลนหน้า (ตำแหน่งครีบและท่าไข่หลังหมุนอยู่ที่ `meta.egg_runouts.*.fins / turned`)
- **ทางลงทุกรางโค้งรับเข้าพื้น:** ต่อจากบาน/สะพานด้วยแผ่นเรียบหลายท่อนที่ความชันลดทีละเท่าๆ กันจนแนบพื้นที่ร่อง X = G แล้วเป็นแอ่ง + กันชนโฟม ผิวบนที่กึ่งกลางเลนอยู่ที่ `meta.egg_runouts`

**การแปลงเข้า Three.js (Y ชี้ขึ้น):** ใส่ทุกชิ้นไว้ใน `root = new THREE.Group()` แล้วตั้ง `root.rotation.x = -Math.PI/2` และ `root.scale.setScalar(0.001)` (แปลงเป็นเมตร)
ผลคือพิกัด (x, y, z) ในสเปก จะไปอยู่ที่ (x, z, −y) ใน Three.js ด้านหน้าของเครื่องจะหันเข้าหากล้องที่อยู่ฝั่ง +Z

## 2. รูปทรง (`parts[].shape`)

| shape | ฟิลด์ | วิธีสร้างใน Three.js |
| --- | --- | --- |
| `box` | `min`, `max` (มุมตรงข้ามของกล่อง) | `BoxGeometry(dx,dy,dz)` แล้ววางที่จุดกึ่งกลาง |
| `cylinder` | `center`, `radius`, `length`, `axis` = x\|y\|z | `CylinderGeometry` (ค่าเริ่มต้นตามแกน Y) แล้วหมุนให้ตรง `axis` |
| `prism` | `plane`, `points` [[u,v]...], `extrude` [from,to] | `Shape` + `ExtrudeGeometry(depth = to−from)` แล้วจัดแกนตามตารางด้านล่าง |

`prism` คือรูปหลายเหลี่ยมในระนาบหนึ่ง แล้วดันออกไปตามแกนที่สาม ใช้กับชิ้นที่วางเอียง เช่น พื้นถาด ทางลาด ผนังคางหมู และสไลด์

| plane | u | v | ดันตามแกน |
| --- | --- | --- | --- |
| `xz` | X | Z | Y |
| `yz` | Y | Z | X |
| `xy` | X | Y | Z |

ถ้าชิ้นใดมี `transform.rotate` = {axis, deg, pivot} ให้หมุนชิ้นนั้นรอบ `pivot` ตามกฎมือขวา ตอนนี้มีเฉพาะจอกับ Pi ที่เอียง 35°

## 3. กลุ่มชิ้นที่ขยับได้ (`groups[]`)

ชิ้นใน `parts` วาดไว้ใน**ท่าอ้างอิง** คือท่าที่ค่าสถานะเป็น 0 ตอนโหลดโมเดลต้องตั้งทุกกลุ่มไปที่ `motion.default` ก่อน

| `motion.type` | ความหมาย |
| --- | --- |
| `rotate` | หมุนรอบ `pivot` ตามแกน `axis` (เวกเตอร์หนึ่งหน่วย กฎมือขวา) เป็นมุม `states[ชื่อ]` องศา |
| `translate` | เลื่อนตาม `axis` เป็นระยะ `states[ชื่อ]` มม. |
| `spin` | หมุนต่อเนื่องรอบ `pivots[partId]` ตาม `axis` ด้วยความเร็ว `rpm` เมื่ออยู่ในสถานะ ON |

- กลุ่มที่มี `follows` จะเปลี่ยนสถานะพร้อมกลุ่มหลัก เช่น `esc.F.p1` และ `esc.F.p2` เปลี่ยนตาม `esc.F`
- วิธีทำใน Three.js: สร้าง `pivotObj` วางไว้ที่ `pivot` แล้วใส่ mesh ลงไปโดยหัก offset ของ pivot ออก จากนั้นหมุนด้วย `pivotObj.quaternion.setFromAxisAngle(axis, rad)`

| กลุ่ม | สถานะ (default เป็นตัวหนา) |
| --- | --- |
| `esc.F/B` (+ `.p1`, `.p2`) | **HOLD** +18.9°, RELEASE −18.9° (หมุดคู่ขึ้นลง ±8 มม.; P1 ที่ X 168, P2 ที่ X 118.5 ปรับได้ 114–124) |
| `k0.F/B` | **REST**, KICK (ยกขึ้น 22 มม.) |
| `f1.F/B` | **STOP** +12.5°, BRIDGE −5.5°, REJECT −34.9° (เลนหน้า) / −32.5° (เลนหลัง) — บานยาว 135 บานพับฝั่งซ้ายที่ X 268, Z 117 ชี้ไป +X |
| `k1.F/B` | **REST** −8°, KICK +70° |
| `k2.F/B` | **STOP** +25°, BRIDGE −2°, DROP −43.1° (เลนหน้า) / −39° (เลนหลัง) — บานยาว 80 (MG996R) |
| `roller.F/B` | **OFF**, ON (120 rpm) |
| `insert.reject/A/B` | **IN**, OUT (ดึงออกด้านหน้า 290 มม.) |
| `ai.window` | **CLOSED**, REMOVED |

## 4. แอนิเมชัน (`animation.json`)

- `sequences[].keyframes[]` แต่ละจุดมีฟิลด์ดังนี้
  - `t` เวลาเป็นวินาที
  - `egg.pos` ตำแหน่งกึ่งกลางไข่
  - `egg.long_axis` แกนยาวของไข่ ค่า `y` คือกลิ้งไปตาม X ค่า `x` คือกลิ้งไปด้านหน้า
  - `set` สถานะของ actuator ที่เปลี่ยน ณ เวลานั้น
  - `event` และ `note` ข้อความไว้แสดงบนจอ
  - `egg.spin_rpm` + `egg.spin_axis` (เวกเตอร์ เช่น `[0, -1, 0]`) ไข่หมุนอยู่กับที่บนลูกกลิ้ง สวนทางกับลูกกลิ้งที่หมุนรอบ +Y
- ตำแหน่งไข่ให้ interpolate เชิงเส้นระหว่าง keyframe ที่มี `pos` (`rest` ใช้ตรวจการชนใน `check.py` เท่านั้น)
- เปลี่ยนสถานะ actuator แบบ tween ประมาณ 0.2 วินาที
- ไข่: ทรงรีรัศมี (24, 32.5, 24) เมื่อ `long_axis = y` มุมกลิ้ง = ระยะทาง / 24 rad (ค่าอยู่ที่ `meta.egg_radii_long_axis_y`)
- `actuators` = `{ group id: [สถานะ] }` 12 กลุ่มที่ sequence สั่ง (กลุ่ม `esc.*.p1/p2` เปลี่ยนตาม `esc.*` เอง)
- `lights` = `{ light id: { parts, states, default } }` บอกว่า `light.top` และ `light.candle.F/B` สลับ emissive ของชิ้น LED ชิ้นไหน
- `demo_playlist[].queue` = ไข่รอในถาดป้อน `[{t, pos}]` (เวลาของ playlist) ไข่ทุกฟองโผล่ตั้งแต่ t = 0 ที่ช่องคิว แล้วเลื่อนลงทีละช่องเมื่อ escapement ปล่อยฟองก่อนหน้า (ถาดจุเลนละ 3 ฟอง)
- `demo_playlist` คือลำดับเล่นต่อเนื่องที่สลับ 2 เลน ใช้โชว์ว่า 2 เลนทำงานพร้อมกัน แต่ละรายการมี `end_pos` = จุดพักสุดท้ายในถาดหน้าแทนตำแหน่ง keyframe สุดท้าย ไข่ที่ลงแถวเดียวกันจะต่อคิวถอยไปทาง +Y ไม่ทับกัน เมื่อเล่นวนรอบใหม่ให้ล้างไข่ทั้งหมด

## 5. ผลการตรวจ (`tools/check.py`)

- ชิ้นที่อยู่กับที่ไม่ทับกันเลย ยกเว้นคู่ที่ตั้งใจให้สอดผ่านกัน เช่น เพลาทะลุผนัง และหมุดทะลุร่องพื้นถาด
- ทุกกลุ่มกวาดผ่านทุกสถานะแล้วไม่ชนชิ้นที่อยู่กับที่
- ชุดรางทั้ง 3 ชิ้นดึงออกด้านหน้าได้ตลอดระยะ (โดย F1 และ K2 อยู่ที่ STOP)
- ไข่ในทุกท่าพักของทั้ง 6 ลำดับไม่จมเข้าไปในชิ้นส่วน (ตรวจด้วยไข่ออกแบบ 48 × 65)
- ไข่ตลอดเส้นทางที่ keyframe ปลายมี `path: true` ไม่จมเข้าไปในชิ้นส่วน (สุ่มทุก ~2 มม.): ลูกกลิ้ง → F1 → สะพานตายตัว → แท่นชั่ง → K2 → ทางลง → แอ่ง → ถาดหน้า ทุกราง
- ไข่ในแอ่งรางเสียต่ำกว่าผิวล่างสะพานตายตัว ≥ 3 มม. และไม่เข้าใต้ load cell ; ไข่ในแอ่ง A (รวมท่าหลังหมุน) ต่ำกว่าสะพาน K2→B ≥ 3 มม. (เหลือ 3.9)
- ช่องต่อ: ปลาย F1/K2 ทุกท่า → แผ่นรับ/สะพานตายตัว ≤ 2 มม. (1.5), สะพาน → แท่นชั่ง 2.0 มม. (≥ 1.5), แท่นชั่ง → แผ่นส่งต่อ 1.5 มม.
- แรงกระแทกตอนไข่ลงถึงพื้น (ความเร็วตั้งฉากผิวที่จุดหักมุม) ≤ 0.3 m/s ทุกลำดับ (มากสุด 0.29 ที่ราง A เลนหลัง) และท่อนโค้งรับยาว ≥ 10 มม. (รัศมีโค้งใหญ่กว่าไข่มาก)
- ความยาวเครื่อง ≤ 1000 มม. (ตอนนี้ 985.2)
- ตำแหน่ง P2 X 118.5 คำนวณให้ใช้ได้กับไข่เบอร์ 5 ถึงไข่ออกแบบ: ไม่แตะไข่ฟองแรก และขึ้นหน้ากึ่งกลางไข่ฟองที่ 2 อย่างน้อย 5 มม. ช่วงที่ใช้ได้กว้างราว X 117–120 จึงต้องจูนกับไข่จริงด้วยร่องปรับ
- interlock เดิม 2 กรณี (ยังคงไว้ในซอฟต์แวร์ตาม D14) ตอนนี้ `check.py` ข้อ 6 ตรวจแล้วไม่ชน เพราะไข่เลนหลังหมุนแล้วกลิ้งไปด้านหน้าที่ X เลยปลายบานที่พับลง
  1. ขณะไข่เลนหลังอยู่ในราง A ห้ามสั่ง K2 เลนหน้าไป DROP
  2. ขณะไข่เสียเลนหลังอยู่ในแอ่ง/กลิ้งไปถาดหน้า ห้ามสั่ง F1 เลนหน้าไป REJECT
- ลำดับไข่เสีย: F1 ไป REJECT ก่อน แล้ว K0 จึงดีดไข่ลงทางลาด (บานไม่มีขอบกั้นที่ปลาย)

## 6. สิ่งที่ไม่ได้ทำเป็นรูปทรงจริง

ส่วนต่อไปนี้ไม่ได้ขึ้นเป็นรูปทรง ถ้าอยากให้เห็น ทำเพิ่มได้ด้วย CSG หรือ decal
- ร่องหมุด escapement
- แอ่งบนแท่นชั่ง (Ø40 ลึก 2.5 ที่ X 485.6) ในโมเดลวางไข่บนผิวเรียบที่ Z 121.2 ของจริงไข่จะจมลงไปอีก 2.5 มม.
- ม่านยาง/แปรงกันแสงที่ช่องผนังระหว่างตู้ AI กับกล่องชั่ง (ช่องเลนเปิดลงถึง Z 74–78 ตามที่บาน F1 กวาดผ่าน)
- แผ่นรับ (`out.*.runout.*`) และทางลาด B (`out.B.ramp.*`) ทำเป็นแผ่นเรียบหักมุม ชิ้นจริงทำเป็นโค้งต่อเนื่องได้ ทำเป็นชิ้นรายเลนที่ผิวคงที่ตาม Y จึงสูงต่างจากพื้นโฟมที่ขอบเลนได้ราว ±3 มม.
- สายไฟ น็อต และรูต่างๆ
